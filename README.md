Customer Retention & Churn Analysis (Telco Customer Churn Dataset)

This project focuses on analyzing and visualizing customer retention and churn behavior using the Telco Customer Churn Dataset. The main objective is to extract meaningful insights that help in understanding why customers leave (churn) and how businesses can improve customer retention strategies.

As part of my internship at Future Intern, I worked on end-to-end data analysis, including data cleaning, processing, and dashboard creation.

🔧 Tools & Technologies Used:
Python (Pandas) – for data cleaning and preprocessing
Microsoft Excel – for initial data exploration and formatting
Power BI – for interactive dashboard creation and data visualization

📌 Key Responsibilities:
Cleaned and transformed raw dataset using Pandas (handled missing values, duplicates, and formatting issues)
Performed data validation and preprocessing in Excel
Built interactive Power BI dashboards to analyze:
Churn rate and retention trends
Customer demographics
Contract types and tenure
Service usage patterns

📈 Key Insights:
Identified factors leading to high customer churn
Found that short-term contracts have higher churn rates
Analyzed impact of services and pricing on customer retention
Discovered key customer segments with strong loyalty
